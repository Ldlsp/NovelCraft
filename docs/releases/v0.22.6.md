# NovelCraft v0.22.6

首个 GitHub 公开发行候选版本，面向希望在 Android 设备上本地创作长篇网文的作者。

## 亮点

- 本地 SQLite 保存作品、章节、资料卡和大纲；API Key 通过 Android Keystore 加密保存。
- 从灵感到开书资料、第一章、章节计划、场景分镜和续写的完整创作流程。
- AI 正文实时显示在编辑器；后续新章节自动生成标题，首行不再留空。
- 长篇连续性工具：人物/关系/伏笔/锚点/禁区、章节闭环和本地质量门。
- 导入 TXT、Markdown、DOCX、EPUB、PDF；导出 Markdown、DOCX、EPUB、PDF；支持 JSON 项目备份。

## 推荐配置：Surper Ai

NovelCraft 支持 OpenAI 兼容 API。推荐在应用“我的 -> 文本创作模型”填写：

```text
Base URL: https://surperai.top/v1
API Key: 你的 Surper Ai API Key
模型名称: Surper Ai 控制台中可用的模型
```

访问 [surperai.top](https://surperai.top/) 获取当前可用模型、价格、额度和服务公告。Surper Ai 为可选服务，NovelCraft 也支持其他兼容接口。

## 安装

下载本发行中的 `NovelCraft-v0.22.6-debug.apk`，允许系统安装来自该来源的应用后安装。本次首发附件为 debug 签名测试包；若设备已安装不同签名的版本，Android 需要先卸载旧版本。

## 已知边界

- 需要 Android 8.0（API 26）或更高版本。
- 本次 APK 使用 debug 签名，仅适合测试和体验；后续正式发行将使用独立发布签名。
- AI 功能需要作者自行配置兼容 API，网络、模型能力与费用由所选服务决定。
- 不要在 Issue、截图或日志中公开 API Key、小说正文或项目数据库。

## 维护者发行步骤

1. 在 GitHub 仓库 Secrets 中设置 `RELEASE_KEYSTORE_BASE64`、`RELEASE_STORE_PASSWORD`、`RELEASE_KEY_ALIAS`、`RELEASE_KEY_PASSWORD`。
2. 确认 `versionName` 为 `0.22.6`、`versionCode` 已递增，运行 `./gradlew testDebugUnitTest assembleRelease`。
3. 提交并推送代码后，创建并推送标签：`git tag v0.22.6 && git push origin v0.22.6`。
4. GitHub Actions 会生成签名 APK 并创建 GitHub Release；下载后在实体设备完成安装验证。
