# 墨舟移动工作台 UI 决策

设计问题：网文作者在手机上续写时，怎样同时保持正文专注、章节定位和长期设定可见。

本次按 UI 设计流程比较了三种结构：

1. 编辑器优先：顶部章节轨道，中部占满屏幕的正文，底部只保留续写和保存动作。
2. 项目总览优先：先显示进度、章节卡片与待解决伏笔，再进入正文。
3. 记忆优先：正文和可折叠的角色、时间线、伏笔卡片并列。

结论：生产界面采用 1 为主，吸收 2 的章节轨道与 3 的“本次续写上下文”摘要。手机上不保留三套实验布局，也不让资料卡常驻挤压正文。作者可从顶部标签进入大纲、记忆和审核；AI 续写前会明确显示本次送入模型的本地上下文数量。

这是一次设计决策记录，不是应用内原型或试验路由。
