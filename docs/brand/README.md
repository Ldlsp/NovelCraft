# NovelCraft Brand Mark

`novelcraft_logo_mark.xml` is the canonical application mark. It combines a paper boat, an open manuscript, and a brush under a cinnabar seal field.

- Cinnabar: `#C8401A`
- Ink: `#1C1C1E`
- Paper: `#FFFDF8`
- Accent paper: `#F4D7CA`

Use the mark without stretching, recoloring, or adding text inside the symbol. The Android launcher foreground uses the same construction.
