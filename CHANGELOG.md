# Changelog

All notable changes to NovelCraft are documented in this file.

## [0.22.6] - 2026-07-27

### Added

- Local-first Android fiction workspace with Room/SQLite persistence.
- OpenAI-compatible model configuration with Android Keystore-encrypted API keys.
- Project ideation, chapter planning, beat sheets, streaming prose, chapter titles, and batch writing.
- Story cards, relationships, anchors, pacing, quality gates, and chapter lifecycle checks.
- TXT, Markdown, DOCX, EPUB, and PDF import/export plus JSON project backup and restore.
- Optional recommended Surper Ai configuration using `https://surperai.top/v1`.

### Fixed

- New AI-generated chapters now receive titles and no longer begin with an empty line.
- Streaming prose now appears directly in the editor instead of only appearing after generation completes.
